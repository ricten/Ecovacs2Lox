# Vorlage für das LoxBerry-Wiki

`ecovacs2lox_start.txt` ist die Seite für das [LoxBerry-Wiki](https://wiki.loxberry.de/plugins/start) im **DokuWiki-Format** (Aufbau wie bei den anderen Plugins: Plugin-Daten, Überblick, Installation, Konfiguration, Referenz, Miniserver-Anbindung, FAQ, Changelog). Rico lädt sie selbst ins Wiki hoch.

## Vor dem Einstellen anpassen

- Die Zeile „Diskussion“ der Plugin-Daten steht noch auf `FORUM-LINK-EINTRAGEN`: nach dem Posten im LoxForum den Link eintragen.
- Bild `plugins:ecovacs2lox:ecovacs2lox.png`: Datei `docs/logo/ecovacs2lox.png` im Medien-Manager des Wikis hochladen (Namensraum `plugins:ecovacs2lox`).
- **Status** („BETA“) und **Min. LB Version** („4.0.0.0“) prüfen; die Version steht in `ecovacs2lox/plugin.cfg`.
- **Release Download** muss genau **eine nackte ZIP-URL** sein (`…/releases/latest/download/ecovacs2lox.zip`), sonst ist das Plugin im Shop nicht installierbar. Bei jedem Release nur **Version** und die Changelog-Tabelle nachziehen.

## Einstellen

Die Seite gehört in den Namensraum `plugins:ecovacs2lox:start`. Das Anlegen setzt ein Wiki-Konto bzw. die Freigabe durch das LoxBerry-Team voraus.
